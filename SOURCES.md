# Sources

Use current installed-library documentation for version-sensitive API details.

## BLAS / LAPACK

- Netlib BLAS: https://www.netlib.org/blas/
- Netlib LAPACK: https://www.netlib.org/lapack/
- CBLAS headers/documentation distributed with Reference LAPACK.

## FFTW

- FFTW 3.3.11 User Manual: https://www.fftw.org/fftw3_doc/

## MUMPS

- Official MUMPS documentation: https://mumps-solver.org/doc/
- The practical notes target the modern MUMPS C interface. Check the exact
  installed MUMPS version before relying on version-specific control defaults.

## Toeplitz preconditioning

- G. Strang, “A Proposal for Toeplitz Matrix Calculations,” Studies in Applied
  Mathematics 74(2), 171-176, 1986.
- T. F. Chan, “An Optimal Circulant Preconditioner for Toeplitz Systems,”
  SIAM J. Sci. Stat. Comput. 9(4), 766-771, 1988.
- R. H. Chan, G. Strang, “Toeplitz Equations by Conjugate Gradients with
  Circulant Preconditioner,” SIAM J. Sci. Stat. Comput. 10(1), 104-119, 1989.
- T. F. Chan, J. A. Olkin, “Circulant preconditioners for Toeplitz-block
  matrices,” Numerical Algorithms 6, 89-101, 1994.
- R. H. Chan, X.-Q. Jin, block-preconditioning literature for structured block
  systems.
- Y. Saad, *Iterative Methods for Sparse Linear Systems*, for ILU and Krylov
  background.
